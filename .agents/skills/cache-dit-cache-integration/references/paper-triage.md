# 新 paper 的 triage 流程

目标：**在 1 小时内给出"接 / 观察 / 不接"**，并对每条判据留下证据。不要先跑实验再判断——绝大多数论文在纸面上就能判掉。

## 0. 一小时流程

| 步 | 动作 | 产出 |
|---|---|---|
| 1（10 min） | 读 Abstract + 贡献列表 + 方法首段的伪代码 | 它打哪一层（①when / ②how much / ③what / 都不是） |
| 2（15 min） | 对照 `SKILL.md` §2 的"论文常打的东西 → cache-dit 对应物" | 哪些已被覆盖 |
| 3（15 min） | 过下面 12 条必查点 | 每条的判据与证据页码 |
| 4（10 min） | 看基线表里有没有块级方法、加速档位覆盖到哪 | 收益是否落在 >5x |
| 5（10 min） | 估落点与改动文件数 | 裁定 + 一句话理由 |

## 1. 十二条必查点（4 组 × 3）

### A 定位

| # | 查什么 | 看哪里 | 判据 |
|---|---|---|---|
| A1 | 它到底修哪一层 | Intro 的贡献列表 + 方法首段 | 若声称同时修多层的（如 DiCache 同时做 when+how），要**逐层拆开判**，别整体接受 |
| A2 | 跳过粒度 | 伪代码里"哪些层被跳过" | 整步 / 块区间 / 逐层 / 逐 token。整步与逐层都超出 cache-dit 现模板 |
| A3 | 是否要求"一个 block 都不算" | 伪代码的循环体 | 要求 `Fn=0` ⇒ 现模板无法表达，必须新增粒度（10 处改动） |

### B 判据（"when" 的信息来源）

| # | 查什么 | 看哪里 | 判据 |
|---|---|---|---|
| B1 | 信号是**实测**还是**先验** | 方法里的判据公式 | 离线曲线/多项式/经验律 ⇒ 信息上弱于 cache-dit 的实测；探针实测 ⇒ 与 `Fn` 同源，看 A2/A3 |
| B2 | 是否要 **per-model 离线产物** | Implementation Details、附录、代码仓库 | 要曲线/basis/系数文件 ⇒ 大幅降权。cache-dit 目前零 per-model 产物 |
| B3 | 误差是瞬时还是累积，守卫是否等价 | 判定公式 | cache-dit 已有 `max_accumulated_residual_diff_threshold` 与 `max_continuous_cached_steps`，两者都只是"可选开关" |

### C 替代算子（"what"）

| # | 查什么 | 看哪里 | 判据 |
|---|---|---|---|
| C1 | 复用 / 外推 / 混合，**有没有 horizon 参数** | 预测公式 | 无 horizon ⇒ 是"更好的复用"而非"更好的预测"，误差画像完全不同（不炸但停更） |
| C2 | 缓存对象是哪个张量 | 方法定义 | 是 `hidden_states` / 块间 residual / 整步输出 / attention states？前两者 cache-dit 已有；整步输出需改粒度；attention states 属另一套系统 |
| C3 | 成本：需要几个历史样本、多少显存、多少算力、有没有不可编译算子 | 方法 + 附录 | 快照数 × 缓存张量 = 额外显存（DMD 是 6×）；SVD/eig/lstsq 在 `@torch.compiler.disable` 外会碎图 |

### D 证据

| # | 查什么 | 看哪里 | 判据 |
|---|---|---|---|
| D1 | **基线里有没有块级方法（DBCache 或等价物）** | 主实验表 | **没有就是最大红旗**。只与 TeaCache/EasyCache/FORA 比的文章，无法证明它优于块级复用 |
| D2 | 数字自洽性与档位 | 主实验表 + 消融 | ①加速后指标**反超**未加速基线 → 可疑；②PSNR 与 SSIM 背离要逐指标读；③档位只在 ≤4x ⇒ 打的是舒适区；④只测单一模型 |
| D3 | 与量化/蒸馏/稀疏注意力/并行的验证 + 能否验收 | 实验节、附录 | 多数论文只测"可与 X 叠加"不做数字；且不提供 raw-float / 逐比特证据 ⇒ 落地后无法验收 |

## 2. 反例三则（说明判据怎么用）

### 2.1 DiCache → 不接（2026-11-17 裁定）

| 判据 | 事实 | 结论 |
|---|---|---|
| A2/A3 | 整步跳过，但每步仍跑 `m=1` 层探针并丢弃其结果（`y = x + R`） | 粒度超出模板，且复用构造比 DBCache 的 `H(Fn)+R_Bn` **更差** |
| B1 | 相对 L1、累积误差、`resume from probed layer` | 三项与 `similarity()` / 累积守卫 / Fn 结构**逐项同源** |
| B2 | 无离线产物（加分） | — |
| D2 | 2.45× / 2.34× / 3.22× | 全在 cache-dit 舒适区 |
| D1 | 基线与 TeaCache/TaylorSeer/EasyCache/ToCA 比 | **没有块级方法** ⇒ 无法证明优于 DBCache |
| C1 | 双锚 + 实测距离比（DCTA）是真新件 | 唯一残值；但要改 `approximate()` 签名穿主路径 |

→ 裁定"不接"。**教训：一篇论文里"新件"和"整体"要分开判；整体不接不等于每个组件都没价值，但残值不足以抵消改动面时，一并搁置。**

### 2.2 MagCache → 不接（保留"仅调度"这一条后路）

- B1 先验（离线 γ 曲线）→ 弱于实测；
- B2 需要 per-model 曲线，且运行期**不可能**自测（要决定第 t+1 步就得知道 γ_{t+1}，而它需要 r_{t+1}）；
- B3 `K` / `E_t` 与 cache-dit 两个守卫语义等价；
- D2 同算力档（~2.7x）PSNR 21.35 vs 块级 31.53 ⇒ 整步复用差 ~10 dB。

### 2.3 HiCache → 可接（成本最低的一类）

- C1 换基，不改 horizon 结构 ⇒ `approximate()` 里改一行；
- B2 只有 σ 这个调参（不是文件）⇒ 可接受；
- D2 增益（+0.04 IR @5.55x）落在噪声内，但成本仅 ~40 行，值得当实验性开关；
- 风险写在纸面上：σ=1.0 时比 Taylor 更差，必须先扫 σ 再下结论。

## 3. 论文修辞 → 怎么验

| 常见说法 | 实际含义 | 怎么验 |
|---|---|---|
| "near-lossless" | 作者自定的 dB 门 | 看它自己表里的绝对 dB，与 cache-dit 同档位的绝对 dB 差多少 |
| "outperforms SOTA by X" | X 常小于跨论文噪声 | 问是否同 harness；X ≤ 0.03 IR 一律不采信 |
| "only one sample for calibration" | 承认有 per-model 产物 | 问这份产物怎么随模型发布、模型更新怎么办 |
| "training-free and model-agnostic" | 通常只测 1~3 个模型，全是单流 DiT | 看有没有双流（video+audio）、UNet、少步蒸馏模型 |
| "compatible with quantization / sparse attention" | 多数只做定性图 | 要有同 harness 数字，且量化后精度基线本身就在漂 |
| "we also evaluate on Flux" | 常是"顺便"一档，配置与主实验不同 | 核对 prompt 数、步数、分辨率、`δ/N` 是否一致 |

## 4. 决策树

```
它打的那一层 cache-dit 有吗？
├─ 有（判定信号 / 复用 / 已有 predictor）──→ 不接（除非能证明同 harness 显著更优）
└─ 没有 ──┬─ 是"整步跳过"或"逐层缓存" ──→ 需新增粒度（10 处 + 两份 pattern）
          │                              └─ 收益在 >5x 吗？否 → 不接
          ├─ 是"更好的预测器" ──→ 能落在 CalibratorBase？
          │                       ├─ 能 + 收益在 >5x ──→ 接
          │                       ├─ 能但只在 ≤4x ──→ 观察（记进 landscape.md）
          │                       └─ 不能 ──→ 观察
          └─ 是"调度" ──→ 仅当已有证据表明"固定调度 > 实测自适应"才加 policy
                          （当前无此证据，MagCache 已判不接）；否则不接
```

## 5. 结论模板

```
论文 / 版本 / arXiv 号：
A 定位：层=?，粒度=?，是否需要 Fn=0=?
B 判据：实测/先验=?，离线产物=?（是否满足闸 3 豁免），守卫是否等价=?
C 替代：复用/外推=?，horizon=?，缓存对象=?，额外样本/显存/算力=?
D 证据：基线含块级方法=是/否，档位=?，可疑数字=?，与量化/并行叠加是否验证，能否给逐比特+命中证据
落点：方案 1/2/3/4（见 extension-points.md §3-§6），改动文件数=?
裁定：接 / 观察 / 不接
一句话理由：
若"接"：第一步要做的证伪实验是什么（同 harness、哪个档位、什么判据）
```

落盘两处都要写（草稿进 `.tmp/research/`，版本化回写 `landscape.md` 的 §2 骨架表 + §3 逐维总表 + §4 已判例表），见 `SKILL.md` §8。只写草稿等于没写。
