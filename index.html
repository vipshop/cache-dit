Cache-DiT wheel index

The Cache-DiT wheels with the SVDQuant CUDA extension compiled in are published here, one directory per CUDA toolkit:

  • whl/cu13/ — the PEP 503 index for the CUDA 13 wheels

Install with pip install -U cache-dit --extra-index-url https://vipshop.github.io/cache-dit/whl/cu13/ (the same distribution PyPI serves, tagged with the local version +cu13).

This page and the channel directories below it are regenerated by tools/make_index.py (through tools/publish_index.sh) on the first publish.
